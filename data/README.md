# Data boundary

This public repository contains **synthetic data only**. The synthetic cohort is generated by `scripts/01_generate_synthetic_data.py` and is designed to exercise the validation workflow: repeated screening exams, horizon-specific follow-up eligibility, cumulative outcomes, patient-level splitting, risk predictions, and generic pre-/post-screen feature families.

No patient-level BC Cancer data, internal field names, source extracts, or private modeling datasets are included.
