# Data Boundary and Synthetic Cohort

This public repository contains **synthetic patient/exam records only**. No patient-level BC Cancer record, internal field mapping, source extract, or private modeling dataset is included.

The full synthetic cohort is generated by `scripts/01_generate_synthetic_data.py` and is intentionally gitignored. A small inspectable sample is committed as `data/synthetic/screening_demo_sample.csv`.

## What the generator is designed to exercise

- 1–4 repeated screening exams per patient;
- a fixed set of 1–5 year cumulative baseline risk outputs;
- cumulative outcome labels with horizon-specific follow-up eligibility;
- administrative censoring;
- patient-level train / validation / test splitting;
- useful but imperfect baseline discrimination;
- local structured variables that can add retrospective signal;
- controlled calendar-time shift so temporal validation can contract random-split gains;
- later-time imaging/result variables for a separate short-horizon triage task.

The generator is designed to reproduce the **analytical structure**, not the private cohort's empirical distribution or exact performance values.

## Synthetic QA

`results/tables/synthetic_cohort_qa.csv` reports cohort-level checks by horizon, including:

- eligible exams and cases;
- excluded short-follow-up records;
- follow-up range;
- patient/exam counts and mean exams per patient;
- exams after follow-up end;
- observed cancers after follow-up end; and
- patient split leakage.

The final three violation counts must be zero.
