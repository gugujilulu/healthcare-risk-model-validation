# Original-style aggregate figures

This directory contains selected static, public-facing visual summaries derived from aggregate outputs of the private retrospective analysis.

“Original-style” describes the visual format of the figures. It preserves the visual structure of the validation and robustness work without exposing the original private source package.

The figures summarize ROC curves, grouped calibration, subgroup AUC forests, and first-exam-only sensitivity after public-safe reduction. Patient-level clinical records, prediction rows, ROC coordinate tables, calibration-bin source tables, internal field mappings, original scripts, private modeling datasets, and the internal technical manual remain outside the public repository.

These figures are intended to be read alongside the curated aggregate tables and documentation as portfolio-context evidence summaries.
