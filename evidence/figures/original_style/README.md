# Original-style aggregate figures

This directory contains selected static aggregate figures from the private retrospective analysis, included as public-safe visual summaries.

These files do not include patient-level records, exam-level predictions, ROC coordinate tables, internal BC Cancer field mappings, private modeling datasets, original scripts, or the internal technical manual.

They are included to preserve the visual evidence structure of the original validation and robustness analyses. They cannot reproduce the private analysis without the underlying private data and source assets.
