# Original-style aggregate figures

This directory contains selected static, public-facing visual summaries derived from aggregate outputs of the private retrospective analysis.

“Original-style” describes the visual format of the figures. It does not mean that original private source files, scripts, underlying data, or official result releases are included.

These figures are included to preserve the visual evidence structure of the original validation and robustness work: ROC curves, grouped calibration, subgroup AUC forests, and first-exam-only sensitivity.

They are **not** generated from any patient-level dataset contained in this repository. The repository does not publish the underlying clinical records, prediction rows, ROC coordinate tables, calibration-bin source tables, internal field mappings, original scripts, private modeling datasets, or internal technical manual.

The figures should be read as portfolio-context evidence summaries, not as official BC Cancer results, audited clinical-grade performance estimates, final clinical performance claims, prospective validation, or deployment specifications.
