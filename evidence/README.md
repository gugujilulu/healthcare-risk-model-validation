# Evidence package

This directory contains **curated aggregate-context summaries** from a private retrospective healthcare model-validation project. It is deliberately separated from `results/`, which contains outputs generated by the public synthetic pipeline.

The files under `evidence/` are public-facing derivative summaries. They may summarize patterns observed in private retrospective analysis after public-safe reduction, rounding, and reformatting. The underlying clinical dataset, patient-level records, exam-level predictions, ROC coordinate tables, calibration-bin source tables, internal BC Cancer field mappings, private modeling datasets, original private scripts, the internal technical manual, raw bootstrap replicate rows, and complete private result tables remain outside the public repository.

These artifacts document the analytical evidence structure across external validation, calibration assessment, local adaptation, bootstrap uncertainty, temporal stress testing, first-exam sensitivity, subgroup analysis, decision-curve analysis, and post-screen triage.

Some values are rounded or reformatted for public presentation. The directory is intentionally narrower than the private study archive and is designed to communicate analytical structure and observed retrospective patterns at an aggregate level.

Synthetic runnable outputs remain under `results/`. Synthetic outputs demonstrate methodology; `evidence/` provides curated aggregate context. These are intentionally different evidence layers.
