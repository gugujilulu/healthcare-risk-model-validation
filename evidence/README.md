# Evidence package

This directory contains **curated aggregate-context summaries** from a private retrospective healthcare model-validation project. It is deliberately separated from `results/`, which contains outputs generated by the public synthetic pipeline.

The files under `evidence/` are public-facing derivative summaries. They may summarize patterns observed in private retrospective analysis after public-safe reduction, rounding, and reformatting, but they do not release the underlying clinical dataset, patient-level records, exam-level predictions, ROC coordinate tables, calibration-bin source tables, internal BC Cancer field mappings, private modeling datasets, original private scripts, the internal technical manual, raw bootstrap replicate rows, or complete private result tables.

These artifacts are included to document the analytical evidence structure: external validation, calibration assessment, local adaptation, bootstrap uncertainty, temporal stress testing, first-exam sensitivity, subgroup analysis, decision-curve analysis, and post-screen triage.

They should not be interpreted as:

- an official BC Cancer model release;
- a complete study archive;
- a reproducibility package for the private clinical analysis;
- prospective validation;
- clinical deployment evidence;
- audited clinical-grade performance estimates;
- final clinical performance claims.

Some values are rounded or reformatted for public presentation. The purpose is to communicate the analytical evidence structure and observed retrospective patterns, not to publish a final audited clinical result table.

Synthetic runnable outputs remain under `results/`. Synthetic outputs demonstrate methodology; `evidence/` provides curated aggregate context. These are intentionally different evidence layers.
