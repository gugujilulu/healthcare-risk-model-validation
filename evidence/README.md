# Evidence package

This directory contains **curated aggregate context** from the private retrospective project. It is deliberately separated from `results/`, which contains outputs generated by the public synthetic pipeline.

- `figures/` — selected aggregate, public-safe visual summaries.
- `tables/` — compact context tables needed to understand the evidence chain.

These artifacts contain no patient-level or exam-level records, no internal BC Cancer field mappings, no private modeling dataset, and no raw bootstrap replicates. They are not sufficient to reproduce the private analysis without the underlying clinical data and private source assets.

For the mapping between private analytical layers and public repository artifacts, see [`docs/project_evidence_map.md`](../docs/project_evidence_map.md).

## Figure construction

The SVG figures are reconstructed from the curated aggregate tables (and, for subgroup/imaging analyses, final aggregate summary tables from the private analysis). Patient-level ROC coordinates or predictions are not published.
