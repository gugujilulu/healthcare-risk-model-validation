# Public / Private Boundary

This repository follows an **asset-level public boundary**. The project context and analytical design are public-safe; patient-level data and internal private artifacts are not.

## Publicly included

- selected aggregate project context;
- curated public-facing summary figures;
- curated aggregate context tables;
- generic methodology and technical decisions;
- reconstructed Python implementation;
- synthetic longitudinal screening data;
- synthetic runnable results;
- evidence map linking private analytical layers to public artifacts.

## Not included

- patient-level or exam-level BC Cancer records;
- exam-level private prediction rows;
- private modeling dataset;
- internal field names or mappings;
- ROC coordinate tables and calibration-bin source tables;
- raw capstone source files as a code dump;
- original internal scripts;
- full internal technical manual;
- complete private result tables;
- raw bootstrap replicate rows;
- original private analysis folders;
- NDA or administrative documents.

## How to read the evidence

Files under `evidence/` are **curated aggregate-context summaries**. They document the analytical structure and high-level patterns observed in the private retrospective work after public-safe reduction, rounding, and reformatting.

Files under `results/` are generated by the **public synthetic pipeline**. They demonstrate the runnable methodology on generated data.

The two evidence layers are intentionally separated so that private retrospective context and synthetic runnable outputs retain their own provenance.

## Analytical scope

The repository covers external validation, calibration, prediction-level local model updating, robustness analyses, temporal stress testing, and a separate post-screen triage branch. The Original Mirai image network remains fixed throughout; local adaptation operates on its risk outputs together with structured variables.
