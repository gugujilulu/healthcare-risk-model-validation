# Public / private boundary

This repository is a **public-safe reconstruction** of methodology developed in a private healthcare risk-model validation project and a later independent analytical extension.

## Included publicly

- generic validation methodology;
- reconstructed Python implementation;
- synthetic longitudinal screening data;
- generic feature schema;
- cumulative endpoint and follow-up eligibility logic;
- patient-level splitting and bootstrap logic;
- discrimination and calibration metrics;
- logistic and LightGBM prediction-level updating;
- temporal validation;
- feature-availability / leakage audit;
- public-safe synthetic figures and result tables.

## Not included

- patient-level or exam-level BC Cancer records;
- the private modeling dataset;
- original internal field names or mappings;
- raw capstone source files;
- original internal scripts as a code dump;
- the internal technical manual;
- complete private result tables;
- original private figures intended for internal analysis.

## Contextual results

The README contains only a small amount of aggregate project context that is already used as a high-level portfolio summary. The runnable repository outputs are synthetic and should not be interpreted as reproductions of the private study results.
