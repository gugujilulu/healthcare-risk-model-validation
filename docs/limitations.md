# Limitations and non-claims

- The public dataset is synthetic and cannot reproduce the clinical distribution of the private screening cohort.
- Synthetic figures demonstrate workflow behavior, not clinical performance.
- The repository does not release or recreate the private evidence package.
- The original independent extension was exploratory; some retrospective best-observed held-out choices were informed by test comparisons.
- The public reconstruction improves the selection protocol but does not retroactively change how the original exploratory values were obtained.
- Future-period temporal validation is a stronger stress test than random splitting but is still retrospective.
- The project does not establish prospective clinical utility, deployment readiness, or treatment benefit.
- Decision-curve outputs depend on the chosen threshold range and the validity of the underlying probability estimates.
- The post-screen triage branch is a separate prediction-time task and should not be interpreted as an improvement to pre-screen long-term risk estimation.
- No claim is made that the baseline image model itself was retrained or fine-tuned.
